Commit to GitHub automatically

Paste a fine-grained Personal Access Token with Contents: Read and write on this repo. It is used only in this browser to call the GitHub API directly and is never sent anywhere else or written into the repo. It is kept in localStorage on this device, so it survives closing the tab and reopening the browser later. Use Clear token before using a shared or public computer.

Manual fallback
  1. Press Copy JSON.
  2. Open config/collection.json on GitHub and click the pencil icon.
  3. Select everything, paste, and commit to main.
  4. The next scheduled run picks up the change; no workflow edit needed.
Field order and unknown keys are preserved exactly as they appear in the source file, so anything this editor does not display is still written back untouched.
